# gluestack-ui in can_app

Decision: ADR 0007 (D-50). Installed 2026-10-02 by unit 02-u24.

## Version and engine

- CLI and component source: `gluestack-ui@5.0.3` (npm dist-tag `latest`). The CLI prints "gluestack-ui v5 alpha" at the end of init, so treat the v5 line as pre-release in spirit even though it is the published `latest`. Report to DECISIONS.md.
- Runtime packages, all pinned exact in package.json: `@gluestack-ui/core` 5.0.15, `@gluestack-ui/utils` 5.0.6, `uniwind` 1.12.1, `tailwindcss` 4.3.3, `react-native-reanimated` 4.5.1, `react-native-worklets` 0.10.1, `react-native-svg` 15.15.5, `react-aria` 3.52.1, `react-stately` 3.50.0, `@legendapp/motion` 2.5.3, `tailwind-variants` 0.1.20, `@expo/html-elements` 0.12.5, `babel-plugin-module-resolver` 5.0.3, `babel-preset-expo` 57.0.13 (needed directly by the new babel.config.js).
- Styling engine: UniWind (Tailwind v4, no PostCSS), chosen with `--uniwind`. v5 docs offer NativeWind v5 or UniWind; UniWind is the Expo-only option without a PostCSS build step.
- Docs say Expo >= 50, RN >= 0.72.5; it builds and tests on Expo SDK 57, React 19.2, react-native-web 0.21.

## Theme

`npm run sync:tokens` copies tokens.json and generates `global.css` (UniWind variants light and dark, Tailwind `@theme`) and `src/theme/gluestack.generated.ts`. Never edit them. gluestack's shadcn-style names (`primary`, `foreground`, `border`, ...) are aliased onto CAN tokens in `scripts/sync-tokens.mjs`; every CAN colour is also exposed as `--can-*`. The provider is mounted with `mode="system"` in `app/_layout.tsx` (follows `prefers-color-scheme` on web, OS setting on native).

## Components

Generated by the CLI into `src/components/ui/**`: box, button, input, pressable, select, text, gluestack-ui-provider. Never hand-edit; excluded from eslint, prettier and `check:logical` (its output uses `text-left`). checkbox and modal were generated but fail `tsc` (icon ref and animation types in the 5.0.3 templates), so they were removed; 02-u25 adds them if needed.

## Install trap

`init` and `add` write `.npmrc` with `legacy-peer-deps=true`: delete it (a plain `npm install` works). On a divergent `~/.gluestack` clone, run with `HOME=/private/tmp/<dir>`.

## Bump

`HOME=/private/tmp/gs npx gluestack-ui@<v> add <components> --use-npm --path src/components/ui`, re-pin versions exactly, `npm run sync:tokens`, `npm run verify`, native `expo export`.

- Before: 1,279,817 bytes raw, 332,845 gzip.
- After: 2,780,971 bytes raw, 632,090 gzip (plus 40KB CSS). Cost is the provider pulling reanimated, uniwind and react-aria; no screen uses them yet.

After 02-u25 (civic wrappers on gluestack Button, Text, Box): 2,843,596 bytes raw, 651,411 gzip (+19KB gzip over the 02-u24 figure; the button creator now ships). Civic components import only `../ui/*`; Screen keeps RN SafeAreaView and ScrollView (no gluestack primitive exists for them) and the token-sourced content width. Wrapper text uses the token classes `text-body`, `text-label`, `text-h1` and so on, colours use `can-*` classes, so dark mode follows the generated theme.
